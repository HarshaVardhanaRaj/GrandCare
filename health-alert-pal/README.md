# Prescription Pal

Create a website that contains the following pages. 1 page for prescriptions, 1 home page that shows active alerts, and 1 page home page. I want the home page to be linked to the prescription page by an add prescription button. At the prescription page we can add the prescription by uploading an image, or by inputting the values manually, or by inputting a number. Build all this first
